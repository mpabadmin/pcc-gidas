# PCC gidas – 1040 medkuopa

Ilgalaikė sužeistojo priežiūra lauke (Prolonged Casualty Care): stebėjimo lapas, skysčių balansas ir diurezė, vaistų ir veiksmų žurnalas su priminimais, priežiūros grafikas, turniketų laikai, telekonsultacija, ATMISTER, pasiruošimas evakuacijai.

Statinė PWA, veikia be interneto. Duomenys saugomi tik telefone (`localStorage`, raktai `pcc-*`).

Adresas: https://pcc.1040medkuopa.lt (GitHub Pages iš `main`, failas `CNAME`).

Šaltiniai: JTS CPG „Prolonged Casualty Care Guidelines“ (ID 91, 2021), „Nursing Interventions, Wound Care, and Splint Management in PCC“ (ID 70, 2025), „Telemedicine Guidance in the Deployed Setting“ (ID 94, 2023), PFC Documentation (Telemedical Consultation Guide, 2023).

Atnaujinant: pakeisti `VERSION` faile `sw.js` ir `VER` faile `core.js`.
